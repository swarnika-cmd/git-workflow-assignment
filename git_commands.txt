1. git init -b main
Initializes a new local Git repository in the current directory and sets the default branch name to main.

2. git add <file>
Stages specified modified or newly created files in the working directory so they are ready for the next commit.

3. git commit -m "<message>"
Records a permanent snapshot of all staged changes in the local repository history with a descriptive message.

4. git branch feature
Creates a new parallel branch named feature pointing to the current commit without switching to it yet.

5. git checkout <branch-name>
Switches the active working directory and HEAD pointer to the specified branch (used to switch to feature and back to main).

6. git merge --no-ff feature -m "<message>"
Integrates changes from the feature branch into main while creating an explicit merge commit to preserve branch history.

7. git log --oneline --graph --all
Displays a compact visual ASCII graph of the entire commit history across all branches.

8. git status
Shows the current branch, staged changes, unstaged modifications, and untracked files (confirming .gitignore rules work).

9. git revert HEAD --no-edit
Safely undoes the changes introduced by the most recent commit by creating a new inverse commit on top of the history.

10. git remote add origin <repository-url>
Connects the local Git repository to a remote GitHub repository under the alias origin.

11. git push -u origin --all
Uploads all local branches and their complete commit histories to the remote GitHub repository and sets upstream tracking.
